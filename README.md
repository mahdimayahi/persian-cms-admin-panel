## معرفی

این پروژه یک سیستم مدیریت محتوا (CMS) مدرن است که با تمرکز بر زبان فارسی و طراحی راست‌چین ساخته شده است. هدف، ارائه‌ی یک «سیستم عملیاتی» کامل است؛ نه صرفاً مجموعه‌ای از فرم‌ها. محور اصلی معماری، زنجیره‌ی زیر است:

> هویت ← دسترسی ← داده ← عملیات ← بازبینی و انتشار ← ثبت تغییرات ← پایش ← بازیابی

قابلیت‌های کلیدی:

- رابط کاربری کاملاً فارسی و راست‌چین با فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn)
- تقویم جلالی برای نمایش تاریخ‌ها و ذخیره‌سازی UTC در پایگاه‌داده
- حالت روشن و تاریب (Dark / Light)
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- جست‌وجو و فیلتر پیشرفته در تمام فهرست‌ها
- ثبت گزارش فعالیت (Audit Log) برای تمام عملیات مهم

## امکانات

### داشبورد
نمای کلی از وضعیت سیستم شامل آمار مقالات، کاربران، دیدگاه‌ها، بازدیدها و نمودارهای روند.

### مدیریت محتوا
- **مقالات**: ایجاد و ویرایش با ویرایشگر پیشرفته (MDX Editor)، تصویر شاخص، دسته‌بندی، برچسب و تنظیمات SEO
- **چرخه‌ی انتشار**: پیش‌نویس → در انتظار بازبینی → نیازمند اصلاح → تأییدشده → منتشرشده → بایگانی
- **نسخه‌بندی**: ثبت نسخه‌های مختلف مقاله و امکان بازگشت به نسخه‌های قبلی
- **صفحات**: مدیریت صفحات ایستا با وضعیت انتشار
- **دسته‌بندی و برچسب**: سازمان‌دهی محتوا با رنگ و اسلاگ یکتا

### مدیریت رسانه
آپلود و مدیریت فایل‌ها با پیش‌نمایش، انتخابگر رسانه در ویرایشگر و امکان حذف.

### تعامل کاربران
- **دیدگاه‌ها**: تأیید، رد و پاسخ به دیدگاه‌های بازدیدکنندگان
- **فرم‌ها**: مشاهده و مدیریت پیام‌های دریافتی از فرم تماس

### مدیریت سیستم
- **کاربران**: ایجاد کاربر، تعیین نقش، تغییر وضعیت (دعوت‌شده / فعال / تعلیق‌شده / غیرفعال)
- **نقش‌ها**: کنترل دسترسی مبتنی بر نقش (RBAC) با چهار سطح
- **منوها**: ساختار درختی منوی سایت با کشیدن و رها کردن (Drag & Drop)
- **تنظیمات**: پیکربندی عمومی سایت
- **گزارش فعالیت**: ثبت کامل تغییرات سیستم (چه کسی، چه کاری، چه زمانی)
- **اعلان‌ها**: اطلاع‌رسانی رویدادها برای کاربران

## راه‌اندازی

پیش‌نیازها: [Bun](https://bun.sh/) نسخه ۱.۱ یا بالاتر

```bash
# ۱. نصب وابستگی‌ها
bun install

# ۲. ساخت پایگاه‌داده از روی اسکیما
bun run db:push

# ۳. تولید کلاینت Prisma
bun run db:generate

# ۴. درج داده‌های نمونه
bunx tsx prisma/seed.ts

# ۵. اجرای سرور توسعه
bun run dev
```

سپس پنل روی `http://localhost:3000` در دسترس است.

## حساب‌های پیش‌فرض

پس از اجرای seed، حساب‌های نمونه زیر ساخته می‌شوند:

| نقش | ایمیل | رمز عبور |
|---|---|---|
| مدیر کل | `admin@demo.ir` | `admin1234` |
| سردبیر | `editor@demo.ir` | `editor1234` |
| نویسنده | `author@demo.ir` | `author1234` |
| بازدیدکننده | `viewer@demo.ir` | `viewer1234` |

> هشدار: پیش از استقرار در محیط عملیاتی، حتماً رمزهای عبور را تغییر دهید.

## نقش‌ها و سطوح دسترسی

کنترل دسترسی مبتنی بر نقش (RBAC) با چهار سطح:

| نقش | توضیح |
|---|---|
| `ADMIN` | دسترسی کامل به همه بخش‌ها، مدیریت کاربران و تنظیمات |
| `EDITOR` | بازبینی، تأیید و انتشار محتوا و مدیریت دسته‌بندی‌ها |
| `AUTHOR` | ایجاد و ویرایش مقالات خود (چرخه پیش‌نویس تا در انتظار بازبینی) |
| `VIEWER` | دسترسی فقط‌خواندنی |

چرخه وضعیت کاربر: `دعوت‌شده (INVITED)` ← `فعال (ACTIVE)` ← `تعلیق‌شده (SUSPENDED)` / `غیرفعال (DISABLED)`

## چرخه‌ی انتشار مقاله

```
DRAFT (پیش‌نویس)
   ↓ ارسال برای بازبینی
IN_REVIEW (در انتظار بازبینی)
   ↓ تأیید                ↓ درخواست اصلاح
APPROVED (تأییدشده)    NEEDS_REVISION (نیازمند اصلاح)
   ↓ انتشار                 ↓ بازگشت به بازبینی
PUBLISHED (منتشرشده) ←───────┘
   ↓ بایگانی
ARCHIVED (بایگانی)
```

هر تغییر وضعیت در گزارش فعالیت ثبت می‌شود و نسخه‌های قبلی مقاله قابل بازیابی هستند.

## معماری API

تمام درخواست‌ها از مسیر `/api/*` پاسخ داده می‌شوند:

| مسیر | متدها | کارکرد |
|---|---|---|
| `/api/auth/login` | `POST` | ورود و ایجاد نشست |
| `/api/auth/logout` | `POST` | خروج و حذف نشست |
| `/api/auth/me` | `GET` | اطلاعات کاربر جاری |
| `/api/auth/change-password` | `POST` | تغییر رمز عبور |
| `/api/auth/sessions` | `GET / DELETE` | مدیریت نشست‌های فعال |
| `/api/articles` | `GET / POST` | فهرست و ایجاد مقاله |
| `/api/articles/[id]` | `GET / PATCH / DELETE` | ویرایش و حذف مقاله |
| `/api/articles/[id]/transition` | `POST` | تغییر وضعیت گردش کار |
| `/api/articles/[id]/versions` | `GET` | نسخه‌های مقاله |
| `/api/pages` | `GET / POST` | مدیریت صفحات |
| `/api/categories` | `GET / POST` | دسته‌بندی‌ها |
| `/api/tags` | `GET / POST` | برچسب‌ها |
| `/api/media` | `GET / POST` | رسانه‌ها |
| `/api/comments` | `GET / POST` | دیدگاه‌ها |
| `/api/form-submissions` | `GET` | پیام‌های فرم |
| `/api/menus` | `GET / POST` | منوها |
| `/api/users` | `GET / POST` | کاربران |
| `/api/notifications` | `GET / PATCH` | اعلان‌ها |
| `/api/activity` | `GET` | گزارش فعالیت |
| `/api/dashboard` | `GET` | داده‌های داشبورد |
| `/api/reports` | `GET` | گزارش‌ها |
| `/api/search` | `GET` | جست‌وجوی سراسری |
| `/api/settings` | `GET / PATCH` | تنظیمات |

- احراز هویت بر پایه‌ی کوکی `HttpOnly` با توکن نشست
- هش رمز عبور با `scrypt`
- اعتبارسنجی ورودی با Zod
- ثبت خودکار Activity Log در عملیات حساس
