## Deviations / Implementation Notes for the Lead

1. **Progress bars in reports**: the shadcn `Progress` indicator hardcodes `translateX(-${100-(value)}%)`, so raw counts with `max` would render wrong. Bars pass a computed **percentage** (`(count/max)*100`) instead of `value=count, max=max` — visually identical intent (spec's value/max could not render correctly with this component).
2. **Radix Select/Tabs cannot use `''` values** — used `__ALL__` sentinel in filter Selects and status Tabs, mapped back to `''`/no-filter when building query strings.
3. **Users transfer dialog scope**: transfer dialog only opens on 409 **with** `data.articleCount > 0` (per spec). Backend also returns 409 for users with uploaded media — that path shows the server's Persian message via toast instead (no transfer possible).
4. **Forms CSV export** applies the current active filters (q/status/formName) while fetching all pages — interpreted «rows from all pages» as all pages of the current view.
5. **Activity action dropdown** seeds the 17 known actions client-side, then replaces with the API-returned `actions` array on first successful load (dropdown usable even before/despite load).
6. **Forms row click** implemented as accessible `<button>` inside the sender and subject cells (DataTable generic has no row-level onClick prop and I was not allowed to modify it).
7. Settings header Save button is `type="submit" form="settings-form"` (no double-submit onClick); a second save/reset pair sits at the form bottom.
8. Debounced search (`350ms`) added on all searchable views to avoid a request per keystroke; every filter change resets `page` to 1.
